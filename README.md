# Formicide

A browser real-time strategy game: black ant colony vs red ant colony. Gather food, grow your colony, evolve stronger ants, and destroy the red Queen's Nest before her armies reach yours.

Single-file HTML5 canvas game — no build step, no dependencies. Works with mouse and keyboard or touch.

## Play

Open `index.html` in any modern browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to play it online.

## Controls

**Mouse & keyboard:** left-click or drag a box to select, right-click to command, right-drag or arrow keys to scroll, wheel to zoom. `A` attack-move, `S` stop, `B` build menu (then `1`–`5`), `Q W E R T` structure buttons, `H` home, `P` pause, `Esc` cancel.

**Touch:** tap to select, double-tap to select all of a kind on screen, tap ground/food/enemy to command, drag to scroll, pinch to zoom, use ⬚ Box to drag-select.

## Difficulty

Easy, Normal and Hard change the enemy's economy bonus, build order timing, wave sizes and defenses.
